# Selected Poems
Sara's personal poetry collection, experienced as a physical illustrated storybook. Readers arrive at a closed book, open it and drag the pages. The two-page spread and gutter are essential. Cover title confirmed by Sara: Selected Poems. Actual poems have not yet been supplied; placeholders must be identified. Existing free page-turning components should be reused. User references pin classic children's book illustrations and antique printed serif type. Latest preference: detailed drawing, colored pencil, ink and richer painted foliage over loose watercolor. This first version is a local repository prototype. No publishing system or poem upload workflow is requested yet.
